# Nonviolent FPS

A 3D first-person platforming game developed in Unity as a software engineering project. The game focuses on movement, exploration, environmental challenges, and unique traversal abilities rather than combat.

## 🎮 Overview

This project is a first-person platformer designed around fast movement and exploration. Players navigate challenging environments while using different abilities to overcome obstacles and reach new areas.

The project was created to explore 3D game development, player movement systems, physics-based mechanics, game-state management, and software architecture in Unity and C#.

## ✨ Features

* **First-person movement**

  * Walking and sprinting
  * Acceleration and deceleration
  * Jumping and gravity
  * Smooth camera controls

* **Advanced traversal**

  * Grappling hook system
  * Launch platforms
  * Air control
  * Moving obstacles
  * Platforming challenges

* **Player abilities**

  * Grappling Hook
  * Jumping Boots
  * Ant-Man ability
  * Teleportation

* **Environmental mechanics**

  * Breakable platforms
  * Keys and locked areas
  * Moving obstacles
  * Collectible items
  * Environmental puzzles

* **Game progression**

  * Multiple levels
  * Save and load system
  * Main menu
  * Continue/New Game functionality
  * Player progression tracking

* **HUD & audio**

  * Ability indicators
  * Collectible tracking
  * Subtitles
  * Environmental and gameplay audio

The primary goals of this project were to:

1. Develop a complete 3D game using Unity and C#.
2. Create responsive and engaging first-person movement.
3. Implement physics-based traversal mechanics.
4. Design reusable gameplay systems.
5. Practice organizing a larger software project.
6. Implement persistent player progression and save data.

## 🚀 Getting Started

### Requirements

* Unity Hub
* A compatible Unity version
* macOS or Windows

### Running the Project

1. Clone the repository.
2. Open Unity Hub.
3. Select **Add → Add project from disk**.
4. Select the cloned project folder.
5. Open the project using the appropriate Unity version.
6. Open the main scene and press **Play**.
